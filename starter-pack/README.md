# Topcoder Combinator Starter Pack

This member-facing package contains four challenge fixtures and one centralized `review-context/` directory. Review context JSON files are not duplicated inside challenge folders. Each `challenge-package.json` references the applicable root JSON.

## Add submissions

For the three code challenges, add untouched ZIPs under each `submissions/SUB_00X/` folder. For the ideation challenge, add the three untouched DOCX, PDF or PPTX files in their original formats.

After adding files, update the verification commands and generate SHA-256 hashes. Do not edit original submission artifacts.
